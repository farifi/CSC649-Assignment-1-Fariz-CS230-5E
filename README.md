# # AI-Based Tree Risk Assessment Using CNN

Proposal (CSC649 - Special Topics in Computer Science) - Convolutional Neural Network technique to predict the risk of tree falls and reporting system with Geographic Information System to fill the lack of proper digital system of tree risk assessment and reporting in Malaysia

## Problem
The tree risk assessment in Malaysia still heavily relies on manual inspection, it's time consuming and labor intensive, missing a high risk tree can lead to tree falls causing property damages and injuries.
