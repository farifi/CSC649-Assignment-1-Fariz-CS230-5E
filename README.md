# AI-Based Tree Risk Assessment Using CNN

Proposal for CSC649 Special Topics in Computer Science: using a Convolutional Neural Network (ResNet-50) to classify visible defects and warning signs in photos of Angsana trees in Malaysian urban areas and give a risk level for arborist review.

## Problem
The tree risk assessment in Malaysia still heavily relies on manual inspection, it's time consuming and labor intensive, missing a high risk tree can lead to tree falls causing property damages and injuries.
